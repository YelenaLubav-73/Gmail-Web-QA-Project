# Gmail Web QA Project

## Project Overview

This repository contains manual QA testing documentation created for Gmail Web.

The project focuses on GUI testing, cross-browser testing, cross-device testing, responsive behavior, and defect reporting.

## My Responsibilities

- Performed manual testing of Gmail Web
- Checked GUI consistency across different browsers and devices
- Identified visual and layout issues
- Tested responsive behavior
- Documented defects with clear steps, expected results, actual results, and severity
- Compared application behavior across Windows, macOS, and iOS environments

## Testing Types

- GUI Testing
- Cross-browser Testing
- Cross-device Testing
- Responsive Testing
- Exploratory Testing

## Defects Found

Examples of documented defects include:

- Language names are truncated in the Gmail language dropdown
- Month names are truncated on high-DPI Windows display scaling
